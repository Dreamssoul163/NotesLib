\section{半环与环}

\hypertarget{sec:定义1.1}{}
\noindent\textbf{定义1.1 (半环)}

给定集合$R$, $0\in R$和$R$上的二元运算$+,\cdot$ , 如果:
\begin{enumerate}
    \item $(R,0,+)$是\href{../../01 群论/01 半群与群#nameddest=sec:定义1.1}{交换幺半群},
    \item $(R,\cdot)$是半群,
    \item 对任意的$x,y,z\in R$, 有$z(x+y)=zx+zy$, $(x+y)z=xz+yz$,
    \item 对任意的$x\in R$, 有$0x=x0=0$,
\end{enumerate}
就称$(R,0,+,\cdot)$是一个\textbf{半环}, 有时简写为$R$. 进一步,
\begin{enumerate}
    \item 如果$(R,\cdot)$是交换半群, 就称$(R,0,+,\cdot)$是一个\textbf{交换半环},
    \item 如果存在$1\in R$使得$(R,1,\cdot)$是幺半群,
    就称$(R,0,1,+,\cdot)$是一个\textbf{幺半环}.
\end{enumerate}

\vspace{10pt}

\hypertarget{sec:定义1.2}{}
\noindent\textbf{定义1.2 (环)}

给定集合$R$, $0\in R$和$R$上的二元运算$+,\cdot$ , 如果:
\begin{enumerate}
    \item $(R,0,+)$是交换群,
    \item $(R,\cdot)$是半群,
    \item 对任意的$x,y,z\in R$, 有$z(x+y)=zx+zy$, $(x+y)z=xz+yz$,
\end{enumerate}
就称$(R,0,+,\cdot)$是一个\textbf{环}, 有时简写为$R$. 进一步,
\begin{enumerate}
    \item 如果$(R,\cdot)$是交换半群, 就称$(R,0,+,\cdot)$是一个\textbf{交换环},
    \item 如果存在$1\in R$使得$(R,1,\cdot)$是幺半群,
    就称$(R,0,1,+,\cdot)$是一个\textbf{幺环}.
\end{enumerate}

\vspace{10pt}

\hypertarget{sec:定理1.1}{}
\noindent\textbf{定理1.1}

任给环$R$,
\begin{enumerate}
    \item 对任意的$x\in R$, 有$0x=x0=0$, 从而环一定是半环,
    \item 对任意的$x,y,z\in R$, 有$z(x-y)=zx-zy$, $(x-y)z=xz-yz$.
\end{enumerate}

\noindent{\kaishu 证明.}

\begin{enumerate}
    \item 对任意的$x\in R$, $0x+0x=(0+0)x=0x$, 所以$0x=0$. 同理$x0=0$.
    \item 对任意的$x,y,z\in R$,
    \begin{equation*}\begin{aligned}
        &z(x-y)+zy=z(x-y+y)=zx\quad\implies\quad z(x-y)=zx-zy,\\[-3pt]
        &(x-y)z+yz=(x-y+y)z=xz\quad\implies\quad(x-y)z=xz-yz.
    \end{aligned}\tag*{\qedsymbol}\end{equation*}
\end{enumerate}

\vspace{10pt}

\hypertarget{sec:定义1.3}{}
\noindent\textbf{定义1.3 (可逆元)}

给定幺环$R$和$x\in R$, 如果存在$y\in R$使得$xy=yx=1$, 就称$x$是\textbf{可逆元}.

记$R$的所有可逆元组成的集合为$R^\times$, 则显然$(R^\times,1,\cdot)$是群.
